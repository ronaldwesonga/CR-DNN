# Simulation Results

This directory contains the numerical outputs supporting the CR-DNN simulation study, comprising 54 factorial design cells and 740 paired neural Monte Carlo replications.

## Results files

| File | Description |
|---|---|
| `replication_raw.csv` | Replication-level predictive performance |
| `replication_selection.csv` | Selected tuning parameters |
| `replication_contrasts.csv` | Paired CR-DNN–DNN performance differences |
| `replication_tuning.csv` | Cross-validation tuning results |
| `replication_invariants.csv` | Computational consistency checks |
| `final_cell_stopping.csv` | Sequential Monte Carlo stopping outcomes |
| `dgp_54_cells.csv` | Data-generating mechanism diagnostics |

All results originate from computationally generated simulation data. No confidential patient-level data are included.
