# Simulation

This directory contains the computational implementation and statistical analysis scripts accompanying the CR-DNN manuscript.

## Scripts

- `CRDNN_Production_Sequential.R`: Data generation, classifier implementation, hyperparameter selection and sequential Monte Carlo simulation.
- `build_final_analysis.R`: Consolidation, validation and analysis of the completed neural simulation results.

The simulation comprises 54 factorial design cells and 740 paired neural replications. All simulation data are generated computationally.
