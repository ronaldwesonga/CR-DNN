
# CR-DNN

Deep Classification under Near-isotropy with Covariance Regularisation and High-dimensional Consistency

## Overview

This repository contains the computational implementation and reproducibility materials accompanying the manuscript on covariance-regularised deep neural networks (CR-DNN).

The framework combines scale-matched covariance regularisation with nonlinear classification and examines the relationship between covariance geometry, representation stability and predictive performance.

## Contents

- Covariance regularisation and transformation functions.
- High-dimensional simulation design and sequential Monte Carlo procedures.
- Neural and regularised linear classification methods.
- Statistical evaluation and paired comparative analyses.
- Planck harmonic covariance analysis.
- Cancer follow-up analysis scripts.
- Numerical summaries supporting the manuscript.

## Reproducibility

The analyses were implemented in R using Keras 3 and TensorFlow. Required package versions are documented in the repository.

## Data availability

Simulation data are generated computationally. Planck data are publicly available through the Planck Legacy Archive. The cancer-registry data are confidential and are not distributed through this repository.
